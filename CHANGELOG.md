# Changelog

All notable changes are documented here.

## [2.0.0] - 2026-10-04

### Added

- Ocean-blue responsive dashboard for routes, bookings and live capacity
- Quarkus REST service with validation, OpenAPI, Swagger UI and health checks
- Route creation and atomic capacity-aware booking workflow
- English, German and French settings
- Light, dark and system themes with reduced-motion support
- Native runtime bundles for Windows, Linux and macOS
- Docker image, CI checks, screenshot and learner tutorial

### Changed

- Upgraded the original Angular prototype to Angular 21
- Replaced untyped API calls and placeholder endpoints with a shared typed contract
- Reworked navigation, accessibility, mobile behavior and empty/error states

### Note

- Version 2 uses an in-memory demonstration store; data resets after restart.
